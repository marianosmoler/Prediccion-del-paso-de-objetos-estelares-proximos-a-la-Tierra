Proyecto final del curso de Machine Learing (Talento Tech)

Profesor: Ariel Palazzesi
Tutor: Cristian urquiza
Autor: Mariano Smoler

Descripción: en este proyecto se analiza un dataset que contiene las fechas de acercamientos de cometas y/o asteroides y 
las distancias y velocidades respecto de la Tierra a las cuales pasaron dichos objetos.

Objetivos: predecir el acercamiento a la Tierra de nuevos objetos estelares, sugiriendo fechas, distancias y velocidades.
